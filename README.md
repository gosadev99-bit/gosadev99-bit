## 🤖 Rakaba — Featured Build

**4-agent AI pipeline for B2B sales prospecting:**

```
Company name input
      ↓
🔍 Researcher  — 4 parallel searches via Serper API → Gemini synthesis
      ↓
📊 Scorer      — BANT lead scoring: HOT / WARM / COLD + pain points
      ↓
✉️  Writer      — 3 cold email variants written from user's product context
      ↓
💾 Logger      — Auto-syncs to Google Sheets + Supabase persistence
```

**Full SaaS infrastructure shipped:**
- Clerk production auth (Google OAuth + JWT verification)
- Supabase (PostgreSQL) — users, lead history, usage tracking
- Stripe billing — Free / Pro / Team / Agency plans with webhooks
- Resend transactional emails — welcome, usage warnings, upgrade confirms
- Usage enforcement — per-plan limits with upgrade modal
- Langfuse observability — token + cost tracking per AI call
- Self-deployed Ubuntu VPS — Nginx, PM2, SSL/Certbot
